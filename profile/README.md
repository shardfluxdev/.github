### Your coding setup. Ready in the cloud.

Shardflux runs your coding agents with your setup, without you managing their machines. Claude Code and Codex work on your project in the cloud with your tools, logins and settings, and keep working when you close your laptop.

```sh
npm i -g shardflux
shard setup
cd your-project
shard ./
```

- **Your setup comes along.** Your machine carries your tools, logins, dotfiles, git identity and Claude and Codex settings. Your project's template carries its dependencies, services and secrets. Every agent starts from both, ready to work.
- **Another agent in one step.** Start a fresh agent from the same machine and template, or fork one with its whole running state to try another idea. Each gets its own working area, and shared volumes are shared where you choose.
- **Keeps working when you leave.** Close your laptop and the agent keeps going. `shard` shows every project and agent with the ones that need you first, and the macOS menu bar tells you when one does.
- **Open it where you already work.** The terminal, Claude Desktop, the Codex app, claude.ai or the Claude mobile app.
- **Your agent can run it.** Every step is a `shard` command with `--json`, so your coding agent can set Shardflux up for you.

Building an agent product? The same workspaces run your customers' agents through the [TypeScript SDK](https://www.npmjs.com/package/@shardflux/sdk), the [Python SDK](https://pypi.org/project/shardflux/), the [MCP server](https://docs.shardflux.dev/reference/mcp) and the [HTTP API](https://docs.shardflux.dev/reference/http-api). Plugins for Claude Code, Cowork and Codex are in [shardfluxdev/plugins](https://github.com/shardfluxdev/plugins).
